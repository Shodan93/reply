Primary call-to-action button, used for the single most important action per view.

```jsx
<Button variant="accent" size="md">Jetzt bewerben</Button>
<Button variant="secondary" icon="arrow-right">Mehr erfahren</Button>
```

Variants: `primary` (ink fill, default), `accent` (violet fill, use sparingly — one per screen), `secondary` (outlined), `ghost` (text-only, nav/toolbar contexts). Sizes: `sm`, `md`, `lg`. `icon` takes a Phosphor icon slug.
